Autoescuela OASIS

Proyecto conceptual de identidad y comunicación para una autoescuela. Verde menta, azul eléctrico y tipografía expresiva dan forma a una propuesta cercana y dinámica.

01

El proyecto

Una propuesta conceptual de identidad y comunicación para una autoescuela. El sistema se presenta en un vehículo, piezas para redes, material impreso y una propuesta de página web.

02

Sistema visual

El verde menta y el azul eléctrico se apoyan en un tono oscuro. El logotipo de formas redondeadas convive con una tipografía de lectura clara y con el mensaje «Sin drama. Con carnet.».

03

Aplicaciones

La rotulación del coche, las historias verticales, la placa de la L y las piezas de escritorio comparten colores y tipografía. La propuesta web reúne esa misma identidad en una interfaz digital.
